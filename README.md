# 데굴데굴 팩터랩

PER·PBR·ROE 조건으로 현재 투자 후보를 찾고, 별도 메뉴에서 과거 연도와 지표 조건에 따른 기업별 시장 대비 초과수익을 검증하는 웹 프로그램입니다.

## 실행

Node.js 22 이상이 필요합니다. 별도 npm 패키지를 설치할 필요가 없습니다.

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`에 접속합니다. `PORT` 환경변수로 포트를 바꿀 수 있습니다.

```bash
npm test
npm run build
npm run validate
```

`worker/index.js`는 Cloudflare Workers 형식의 단일 서버 모듈입니다. 개발 서버는 `scripts/dev.mjs`입니다. Git 소스와 게시 버전은 Sites에서 관리합니다.

## 배포 (Cloudflare Workers)

```bash
npx wrangler@4 deploy
```

주소: https://degul-factor-lab.degul-factor-lab.workers.dev · 설정은 `wrangler.toml`. 배포된 사이트에는 실제 데이터 수집 기능(`/api/collect`)이 없으므로 수집 패널이 자동으로 숨겨집니다. 수집은 로컬에서만 실행합니다.

## 구현한 기능

- 현재 검색: PER·PBR·ROE 최소/최대 범위의 AND 필터, 업종·기업명 검색, 정렬, 관심종목, 기업 상세 및 CSV.
- 과거 백테스트: 선정 연도별 당시 재무지표 검색, 기업 직접 선택, 투자금과 편도 거래비용, 기업 수익률·KOSPI 대비 초과수익률(%p)·손익·최대 낙폭, 일별 성과 그래프, A/B 결과 저장 및 CSV.
- 메뉴 간 조건과 기업 전달. 두 메뉴는 독립 실행됩니다.
- 데이터 설정: HTTPS API 주소 및 인증 키 입력, Bearer / X-API-Key / AUTH_KEY 인증, 서버를 통한 JSON 조회, JSON 파일 불러오기와 전체 예제 다운로드.
- 키는 현재 탭 메모리에만 보유하고 URL, localStorage, Git, 파일에 저장하지 않습니다. 관심종목과 비교 결과만 브라우저에 저장합니다.

## API 연결

특정 공급자의 키만으로 모든 데이터를 자동 결합하는 서비스가 아닙니다. 재무지표, 종목 가격과 지수를 함께 담은 **통합 JSON 응답**을 제공하는 API가 필요합니다. 원본 OpenDART/알파밴티지/KRX 응답은 서로 필드와 데이터 범위가 달라 직접 붙일 수 없습니다. 해당 공급자 응답을 아래 계약으로 변환하는 어댑터를 데이터 서버에서 제공하세요. API가 없다면 동일한 형식의 JSON 파일을 업로드해 실행할 수 있습니다.

앱이 API 주소에 GET 요청을 보냅니다. 시작일과 종료일이 필요한 API는 주소에 `from`, `to` 같은 공급자 정의 쿼리를 포함하세요. 인증 키는 선택한 HTTP 헤더로만 전송합니다. 리다이렉트는 허용하지 않으며 외부 HTTPS 주소만 지원합니다. 응답은 최대 12MB입니다. API의 데이터 이용 권한·기간·호출 한도는 사용자의 공급자 계약에 따릅니다.

### 응답 규격

```json
{
  "meta": {
    "source": "공급자 이름",
    "asOf": "2026-10-23",
    "version": "2026-10-23-v1",
    "pointInTime": true,
    "priceBasis": "split-adjusted-ex-dividend",
    "benchmarkName": "KOSPI",
    "universePolicy": "각 기준일 당시 상장된 기업 표본"
  },
  "stocks": [{"symbol":"005930","name":"기업명","sector":"IT","market":"KOSPI"}],
  "snapshots": [{"symbol":"005930","asOf":"2023-04-28","availableDate":"2023-03-20","fiscalYear":2022,"per":10,"pbr":1,"roe":12,"source":"공시 기반","filingId":"접수번호"}],
  "prices": [{"symbol":"005930","date":"2023-05-02","close":60000}],
  "benchmark": [{"date":"2023-05-02","close":2500}]
}
```

이 스니펫은 구조 예시이며 완전한 백테스트 기간을 포함하지 않습니다. 화면의 예제 다운로드에는 바로 실행 가능한 전체 가상 데이터가 포함됩니다.

- `roe`는 백분율 숫자입니다. 12%이면 `12`를 사용합니다.
- `asOf`는 지표의 계산 기준일, `availableDate`는 해당 값을 이용할 수 있게 된 첫 거래일입니다. 공시 날짜만 아는 경우 다음 거래일을 사용하세요.
- `fiscalYear`는 연간 재무연도입니다. 선정 연도 Y의 백테스트는 Y−1 재무연도를 사용합니다.
- 정정된 최신 값이 아니라 당시 알 수 있었던 보고서 버전을 제공할 수 있을 때에만 `pointInTime: true`로 선언하세요. 앱은 이 선언과 시점 필드로 가용성을 판정하지만 원본 공시의 진위를 독립 검증하지 않습니다.
- `prices`는 배당을 제외하고 주식 분할을 조정한 양수 종가입니다. 모든 지수 거래일에 선택 기업의 가격이 필요합니다. 누락 시 확정 수익을 계산하지 않습니다.
- `benchmark`는 기업과 동일한 날짜의 가격지수입니다. 시가총액 지수 자체에 실제 거래를 수행한다고 가정하지 않습니다.
- 현재 검색은 `meta.asOf`까지 이용 가능한 최신 스냅샷을 사용합니다.
- 기존 기업의 현재 목록만 과거에 사용하는 경우 생존편향이 생길 수 있습니다. `universePolicy`에 실제 표본 구성 기준을 적으세요.

## 계산 규칙

선정 연도 4월 마지막 지수 거래일의 이용 가능 정보를 사용하고, 5월 첫 지수 거래일에 매수하여 다음 해 4월 마지막 지수 거래일에 매도합니다. 결과는 연도별 독립 보유 결과입니다.

- 매수수량 = 초기투자금 / (매수가격 × (1 + 매수비용률)). 소수점 수량 허용.
- 최종평가액 = 매수수량 × 매도가격 × (1 − 매도비용률).
- 기업수익률 = 최종평가액 / 초기투자금 − 1.
- 시장대비초과수익률 = 기업수익률 − 동일기간지수수익률. `%p`로 표시.
- 지수비교가정초과손익 = 초기투자금 × 수익률차이.
- 최대낙폭 = 일별 평가액 / 이전 최고 평가액 − 1의 최솟값. 초기 투자금과 거래비용을 반영.

배당은 제외합니다. 세금과 실제 체결 오차는 입력한 편도 비용 가정에 포함할 수 있으며 별도 세법 계산은 하지 않습니다. 과거 성과는 미래 수익을 보장하지 않습니다.

## 검증 범위

테스트는 공시 가용일, AND 필터, 수익률과 지수 비교, 양방향 비용, MDD, 누락 데이터, 기간 범위, API 입력·응답 검증을 확인합니다. 사용자 실거래 API 키가 제공되지 않아 실제 데이터 공급자와의 종단간 연결은 검증하지 않았습니다. 기본 화면은 합성 데이터라고 명시한 기능 체험 모드입니다.

## v1.2 실제 데이터 수집 · 막대 조건 · 거치식/적립식 비교

### 실제 KOSPI·KOSDAQ 데이터 수집
1. OpenDART(opendart.fss.or.kr)와 KRX Open API(openapi.krx.co.kr) 인증키를 발급받습니다. KRX는 `유가증권/코스닥 일별매매정보`, `KOSPI 시리즈 일별시세정보` 서비스 이용 신청이 추가로 필요합니다.
2. 키를 등록합니다: `setx DART_API_KEY "키"`, `setx KRX_API_KEY "키"` (또는 프로젝트 폴더의 `.env` 파일에 `DART_API_KEY=키` 형식으로 작성).
3. `npm run dev` 실행 후 **API 및 데이터 → 실제 데이터 수집**에서 기간을 정해 수집합니다. 터미널에서는 `npm run collect -- --from 2019-01-01 --to 2026-10-28`.

- 매월 마지막 거래일의 전 종목 종가·시가총액과 KOSPI 지수를 받습니다(월말 데이터, `meta.frequency: "monthly"`).
- PER = 시가총액 ÷ 당기순이익, PBR = 시가총액 ÷ 자본총계, ROE = 당기순이익 ÷ 자본총계. 연결재무제표 우선, 없으면 별도. 사업보고서 접수일 다음 날부터 사용합니다.
- 액면분할·병합은 상장주식수와 주가가 반대로 움직인 달을 찾아 보정합니다. 배당은 제외합니다.
- 결과는 `data/krx-dart_시작일_종료일.json`, API 응답은 `data/cache/`에 저장되어 재실행 시 이어서 수집합니다. 키는 파일에 저장하지 않습니다.
- 한계: OpenDART는 2015 사업연도부터 제공합니다. 정정공시 이전 원본 수치를 따로 보관하지 않으며, 당기순이익은 지배주주 귀속분이 아닌 전체 기준입니다. KOSDAQ 종목도 KOSPI 지수와 비교합니다.

### 조건 막대와 투자 방식
- PER·PBR·ROE 입력란 아래 양쪽 막대로 범위를 조절합니다. 막대 끝은 상한/하한 없음(±1000)입니다.
- 백테스트에서 **거치식**(시작일 일괄 매수)과 **적립식**(매월 첫 거래일 같은 금액 매수)을 선택합니다. 두 방식을 같은 총 원금으로 함께 계산해 금액·수익률 차이와 평가금액 추이를 보여줍니다. 적립식 수익률은 총 납입 원금 대비, MDD는 납입 효과를 뺀 시간가중 기준입니다.

## v1.1 과거 조건 검색 후 기업별 백테스트
투자 시작일과 종료일을 직접 입력합니다. 시작일 직전 지수 거래일까지 공개되고 계산된 최신 스냅샷으로 PER/PBR/ROE 조건을 검색합니다. 검색 결과 중 기업을 명시적으로 선택하면 실행 버튼이 나타납니다. 기간이나 지표 조건 변경 시 재검색해야 합니다. 기간 안의 첫 거래일 종가로 매수하고 마지막 거래일 종가로 매도합니다. 최종 평가금액, 손익, 시장 대비 초과수익과 최대 낙폭을 제공합니다. 이전의 고정 1년/전년도 재무연도 규칙 대신 이 규칙이 웹 화면에 적용됩니다.
